# KayKit furniture subset

Author: Kay Lousberg. Pack: KayKit Furniture Bits 1.0. License: CC0, original `LICENSE.txt` retained.

Source: https://github.com/KayKit-Game-Assets/KayKit-Furniture-Bits-1.0/tree/main/addons/kaykit_furniture_bits/Assets/gltf

Shipped: `book_set`, `shelf_B_small_decorated`, `cactus_small_A`, `cactus_medium_A`, `pictureframe_small_A`, `pillow_A` and `book_single` (each `.gltf` / `.bin`), and their shared `furniturebits_texture.png`. Source bytes are unchanged; runtime applies scale/placement and roughness. Build-time embedding makes the existing Client self-contained without an external asset route.

`inspection.json` preserves exact downloaded source URLs, SHA-256, sizes and accessor inspection. It also lists `lamp_table` and `armchair_pillows`, which were evaluated but are **not shipped or loaded**. The seven shipped models total 1,642 triangles before scene instancing.
